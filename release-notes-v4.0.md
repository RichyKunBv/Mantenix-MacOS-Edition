# Mantenix v4.0

## Nueva versión

Mantenix v4.0 llega con una actualización importante orientada a macOS Big Sur 11+ y una experiencia de mantenimiento más moderna, más segura y más clara.

### Cambios principales

- Compatibilidad enfocada en macOS Big Sur (11.0) o superior
- Mejora de seguridad y protección antes de tareas del sistema
- Creación de instantáneas locales de Time Machine para rollback seguro
- Limpieza más profunda de cachés, temporales y archivos residuales
- Revisión de salud del Mac con mejor diagnóstico general
- Comprobación de seguridad del sistema
- Optimización y actualización de Homebrew de forma segura
- Búsqueda automática de actualizaciones del propio script

### Mejora de estabilidad

La versión 4.0 refuerza la limpieza del sistema, la trazabilidad de acciones por log y la prevención de operaciones peligrosas sin confirmación, especialmente en procesos que pueden afectar rendimiento o almacenamiento.

### Requisitos

- macOS Big Sur 11.0 o superior
- Permisos de administrador para ejecutar tareas del sistema
- Conexión a internet recomendada para actualizaciones

## Nota

Esta versión está pensada como una evolución sólida para usuarios de macOS modernos, ideal para uso en beta o prueba con validación adicional en hardware real.
